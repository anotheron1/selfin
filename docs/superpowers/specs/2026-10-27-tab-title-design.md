# ANO-233: вкладка «Selfin», страница — русская

Шаг 2 плана спринта 7 (`2026-10-26-sprint-7-plan.md`). Задача найдена 17.10 при проверке ANO-222 на стенде; в веху «4. Мелочи» её взял владелец 26.10 (решение 1).

## Что было

Стенд, 27.10, экран входа: у вкладки заголовок «Vite + React + TS» — заглушка шаблона Vite; `document.documentElement.lang` — `en`. Причина — `frontend/index.html`: `<title>Vite + React + TS</title>` и `<html lang="en">`. Интерфейс целиком русский, а `lang="en"` говорит браузеру и экранному диктору, что текст английский: Chrome предлагает «перевести с английского», диктор читает русские слова английскими правилами. Это первое, что тестировщики увидят в списке вкладок и закладках. Своего заголовка экраны не ставят — в коде нет ни одного `document.title`.

## Как

* `frontend/index.html`: `<title>Selfin</title>`, `<html lang="ru">`.
* Сторож по исходнику — `frontend/src/indexHtml.test.ts`: страницу тестом не открыть, поэтому сторож читает `index.html`, как `nginxCache.test.ts` читает конфиг nginx.

## Чего не делаем

* **Значок вкладки** — логотип Vite (`public/vite.svg`). Свой значок — веха «5. Дизайн» (план спринта 7, раздел 5). Убрать ссылку без замены не лучше: браузер покажет пустой значок.
* **Заголовок по экранам** («Журнал — Selfin» и подобное) — никто не просил; понадобится — отдельной задачей.
