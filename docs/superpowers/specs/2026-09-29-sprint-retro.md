## 2. Что было трудно

* **Ворота 1 — двадцать кругов Codex.** #86: 25 замечаний, 18 из них P1, за пять с лишним часов. Скрипт восстанавливает по событиям GitHub историю голов PR, реакции Codex и ожидаемые джобы — у такой логики краёв без конца. Остановка — решением владельца, три замечания закрыты ответом.
* **C8 — время на экране.** Шесть P2 Codex за четыре круга, все — пересечения во времени: пауза перед пересчётом, запрос в пути, свёрнутая карточка, нулевая основа, строка взноса, отстающая от примерки. Третий круг владелец закрыл вариантом А: дальше — ответами без правок.
* **Четыре PR за одну ночь.** #123 конфликтовал с #124 и #125 в строках импорта, #101 — с #96. Вливание по одному и прогон сочетаний до вливания сработали, но это ручная работа.
* **Стенд.** В панели браузера нижние листы застывают за краем экрана, `confirm()` молча отклоняется, выпадающий список Radix не открывается с клавиатуры — обходы в 9.1, п. 7 плана. Между задачами стенд уходит от `main`: к концу спринта он собран из ветки C8.
* **Мутации скриптом.** 28.09 набор бэка дважды «покраснел» вхолостую — ошибка компиляции сошла за красное; две многострочные мутации не применились из-за CRLF. Правило записано в 9.2 — то есть в память.

* **Ворота 1 в облаке — снова на честном слове.** Механизм там — только джоба «Ответы Codex» в CI. CI, базу PR и закрываемые задачи я сверяю инструментами руками. Проверить, что Codex смотрел последнюю голову, нечем, если он ответил 👍 без ревью. Это узор 2.
* **Ночь из четырёх PR — четыре ветки.** Либо разрешение на ветки задач в одной сессии, либо по сессии на задачу.
