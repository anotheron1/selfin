## Цикл разработки

Восемь шагов из прошлой передачи в силе. Эта сессия добавила к ним следующее — всё проверено на себе, каждый пункт стоил находки.

### Ревью своего диффа до чужого (новый шаг 7а)

После кода, до пуша — скилл `code-review` по накопленному диффу. В этой сессии дал **четыре находки**, две из них настоящие дефекты, которых не видел ни один из 547 тестов:

* половины одной формулы считали потраченное по-разному, и человек, отмечающий траты правкой строки плана, не получил бы прогноза никогда;
* N+1 на загрузке дашборда: 21 категория × 2 запроса × 2 скоупа.

**Codex на PR — часть цикла, а не постскриптум.** Он дал два P2, оба верные, второй — настоящий дефект логики. Мёрж только после того, как его замечания разобраны.

### Мутация должна ломать ровно одно

Две ловушки, обе поймались в этой сессии:

* **«Мутация», тождественная оригиналу, — не мутация.** Заменил разницу двух чисел на `minForecast − minBalance` и получил зелёное: выражения алгебраически равны. Настоящая мутация потребовала вернуть удалённый накопитель.
* **Тест, несущий сразу две приметы, не краснеет на снятие одной.** Тест на погашенный план ставил и статус `EXECUTED`, и `factAmount`; убери любой фильтр по отдельности — тест проходит. Развёл на две боевые формы — и наткнулся на дефект, который иначе бы уехал в прод.

Правило: **если мутация не покраснела, это находка о тесте, а не о коде.**

### Откат мутации — только по закоммиченному

`git checkout -- file` по незакоммиченному файлу сносит не мутацию, а всю правку. Потерял так работу Задачи 2 и переделывал. Порядок: зелено → коммит → мутации с откатом через `checkout` → при находке правка и `--amend`.

### «До/после» на стенде — замером, а не рассуждением

Утверждение «правка не двигает стенд» проверено так: второй бэкенд поднят из worktree на `main`, опрошен тем же запросом на той же базе. Числа совпали побайтово. Рассуждение «при снятых галочках путь тот же» было верным, но рассуждение — не замер.

### Стенд ловит то, чего не ловят тесты

Оговорка в плашке разрыва говорила «раньше», хотя показывается по признаку «глубже». На стенде прогнозный минимум оказался **позже** планового, и плашка утверждала бы неправду. Это **не поймал ни один из 547 тестов** — поймал взгляд на экран.

Отсюда же: ANO-129 записывает, что восемь дефектов ANO-50 не ловятся тестами по построению. Ручной проход не заменяется автоматом.

### Чужой поехавший тест — находка

На Задаче 4 поехало восемь чужих тестов. Все доказывали старое правило «прогноз внутри кармашка». Переписаны по смыслу, ни один не подогнан числом.

## Что закрыто в этой сессии

**ANO-80** — прогноз текущего месяца больше не экстраполирует одну точку.

| | было | стало |
|---|---|---|
| механизм | дневной темп «факт / номер дня» | `max(0, медиана − потрачено − удержанные планы)` |
| множитель первого числа | ×30 | нет |
| место прогноза | внутри кармашка | второе число рядом |
| медиана | месяцы с тратой | месяцы наблюдения, пустые — нулями |

Пятнадцать коммитов. Прогон: **395 юнитов + 155 интеграционных**, фронт 114, `tsc` чистый. Двадцать мутаций, каждая поймана.

Сверх задачи починено: траты, записанные правкой строки плана, теперь видны норме и окну наблюдения; порог и окно истории сведены в одно объявление вместо двух копий каждого; из нормы вычитается только то, что реально удержано траекторией или бронью.

Заведены: **ANO-159** (плашка не называет виновника без описания у расхода). Отменён как дубль: ANO-160 → ANO-119.

## Грабли этой сессии

**`mvnw` лежит в `backend/`, а не в корне.** Команды в CLAUDE.md написаны от каталога модуля.

**Порт 8080 занят посторонним процессом** (`AgentService`). Локальный бэкенд поднимать на другом порту: `--server.port=8090 --spring.datasource.url=jdbc:postgresql://localhost:5433/selfin`.

**Vite слушает только IPv6.** `curl 127.0.0.1:5175` не отвечает, `localhost:5175` работает. Полчаса можно потерять на пустом месте.

**`perl -0pi -e` молча не матчится.** Несколько раз правка «применилась» без эффекта, и это выяснялось только по результату теста. Для правок длиннее строки надёжнее `Edit`, а после `perl` — обязательный `grep` на результат.

**Стенд поднимается бэкендом из исходников, а не образом.** Образы в докере собраны из старого кода; проверять правку через `docker start selfin-test-backend` бессмысленно.
