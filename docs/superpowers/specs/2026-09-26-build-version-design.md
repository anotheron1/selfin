# Коммит сборки наружу: `GET /api/v1/version` (ANO-194, PR 3 из 4)

Ворота 4 из пяти — ретро 26.09, раздел 4. Спека и план одним документом: шагов немного.

---

## 1. Что сломано

Случай 11 ретро: в точке входа записано «стенд собран из #76», а он был из #75. Выяснилось только пробой ручки. Какой код крутится на стенде или на сервере, сейчас узнаётся по памяти: у образа бэка нет аргумента сборки, compose и публикация образов коммит не передают, ручки версии нет.

## 2. Решение

* **Ручка** `GET /api/v1/version` отдаёт `{"commit": "<коммит>"}`. Коммит — переменная окружения `GIT_COMMIT`, без неё — `unknown`.
* **Образ бэка:** `ARG GIT_COMMIT=unknown` и `ENV GIT_COMMIT=$GIT_COMMIT` в рабочей стадии `backend/Dockerfile`.
* **Публикация в GHCR** (`publish-images.yml`) передаёт `GIT_COMMIT=${{ github.sha }}`.
* **Compose** передаёт `GIT_COMMIT` из окружения. Стенд собирается командой с `GIT_COMMIT=$(git rev-parse HEAD)` — она записана в `docker-compose.test.yml`. Забыл переменную — ручка честно скажет `unknown`, а не чужой коммит.
* **Проверка в CI:** джоба миграций уже собирает образ бэка из PR и поднимает его на базе с данными. Образ собирается с `GIT_COMMIT=${{ github.sha }}`, а скрипт после запуска спрашивает `/api/v1/version` и краснеет, если коммит не тот. Сломанная цепочка «аргумент — переменная — ручка» даёт `unknown` и красную джобу.

Коммит в открытой ручке ничего не раскрывает: репозиторий публичный.

## 3. Правила продукта — сверка

Служебная ручка и сборка; экранов, расчёта и данных пользователя правка не касается.

| правило | как соблюдено |
|---|---|
| 1–4, запреты | не затрагиваются |
| 5–9, требования | не затрагиваются: ответ ручки на экране не показывается |
| 10–13, тексты на экране | не затрагиваются |
| характер плановой строки | не затрагивается |
| данные респондентов | не затрагиваются |

## 4. Как проверяется

* **Юнит-тест** контроллера: отдаёт коммит, с которым создан. Сначала красный — контроллера нет.
* **Проба в CI на настоящем образе** — джоба миграций, после запуска образа из PR.
* **Красное на подсаженной поломке** — черновой PR, где `ENV GIT_COMMIT` из `Dockerfile` убран: проба видит `unknown` вместо коммита, джоба миграций красная. Не вливается.
* **Стенд** — собрать с `GIT_COMMIT=$(git rev-parse HEAD)`, спросить ручку.
