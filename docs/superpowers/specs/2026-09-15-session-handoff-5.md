**Две находки сверх замечаний.** Поднятие плановой суммы через `PUT /events/{id}` оставляло план закрытым с положительным остатком — тот же дефект, четвёртым путём, в замечании его не было. И сброс даты при повторном открытии `FactCreateSheet` брал UTC-дату мимо собственного `max` — замечание касалось только `Fab`.

**Почему предикат остался на статусе, а не на одном остатке** (в замечании предлагалось на выбор): на `status = PLANNED` смотрит не только движок — на него же опирается выборка просрочки, так что честный статус чинит всех разом. Чисто остаточный предикат вернул бы в траекторию **отменённые** планы: у `CANCELLED` тоже `kind = PLAN`, `factAmount = null` и положительный остаток.

Два случая пересчёт пропускает намеренно, оба закрыты тестами: собственный `factAmount` в строке плана (легаси-путь PATCH — пересчёт по детям «открыл» бы исполненный план) и план без плановой суммы (обязательства нет, измерять нечего).

Восемь мутаций, каждая поймана ровно своим тестом. Ответы — в тредах ревью, они же кратко в теле PR.

## Цикл разработки: что добавила эта сессия

### Замечание ревью — вход в разбор, а не техзадание

Два подтверждённых замечания из четырёх оказались шире собственной формулировки: у «статуса» нашёлся четвёртый путь порчи, у «UTC-даты» — второе место. Если чинить ровно написанное, оба остались бы наполовину живы. **Правило: замечание указывает на механизм, а чинится механизм, а не строка.**

### Сторож по исходнику закрывает дыру там, где нет тестового слоя

Компонентных тестов во фронте нет и заводить их ради одной строки дорого. Сторож, читающий исходник (`формам факта запрещено брать дату из toISOString()`), в первом же прогоне оказался красным — и не из-за `Fab`, который я только что починил, а из-за `FactCreateSheet`, которого замечание не касалось. Третий такой сторож в репозитории за две сессии, и второй, чья польза доказана сразу.

### Окружение проверяется запуском, а не рассуждением

«Контейнер, наверное, в UTC» — гипотеза. `docker run --rm maven:...-alpine` → `zone=GMT`, с `-e TZ=Europe/Moscow` → `zone=Europe/Moscow`: факт, и в нём же готовая починка. Две команды, десять секунд.

### Пересчёт честнее отметки — но не везде

Статус плана был отметкой, поставленной один раз, и разъезжался с реальностью при любой последующей правке. Производная не разъезжается по построению. Но два случая пересчёт обязан пропускать — легаси-строку с собственным фактом и план без суммы, — и оба закрыты тестами, а не комментарием: иначе «производная» тихо сломала бы то, чего не понимает.

## Грабли этой сессии

**Правка исходников во время фонового `verify` делает прогон недействительным.** Выброшено два прогона, около двенадцати минут. Пока идёт сборка — исходники не трогать, даже тесты; либо править только другой модуль (фронт при бэковой сборке безопасен).

**Вывод фонового процесса через `| tail` пуст до самого конца** — буферизация. Писать в файл (`> log 2>&1`) и читать `grep`-ом по ходу.

**Maven пишет русский в cp1251.** `tail` на таком файле падает с «stream did not contain valid UTF-8», `strings` в окружении нет. Помогает `grep -a` (и `-a` же нужен для `grep` по логу).

**`mvnw` лежит в `backend/`, не в корне репозитория.** Команда из `CLAUDE.md` запускается из `backend`.

**`duplicateOf` в Linear не просто связывает задачи**, а переводит помеченную в статус Duplicate (отменена). Если нужна связь без отмены — `relatedTo`.
