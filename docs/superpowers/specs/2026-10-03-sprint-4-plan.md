## 6. Цикл

Без изменений (ретро 29.09, раздел 5); этапы не пропускать (владелец 26.09):

разбор inline → спека со сверкой по каждому правилу канона → план → TDD → мутации на итоговом коде → стенд до и после → PR → ворота `tools/pr-ready.sh <N>` → «ждёт ок» → вливание → Linear с комментарием.

* **План** — раздел той же спеки, если шагов немного; иначе файл в `docs/superpowers/plans/`.
* **Вывод или продуктовое решение** — сначала с владельцем в чате, по вопросу за раз: что на экране, развилка таблицей, рекомендация. Вливание с выводом — после его «ок»; механическое — тесты, сторожа, документы без выводов — сам после CI и Codex.
* **Codex** ставит 👀 при открытии PR, минут через десять — замечания или 👍. После пуша правок — `@codex review` отдельным комментарием; в ветках бота через @ не упоминать. Замечание в теле ревью — ответ своим ревью с его заголовком. Убывающие круги после третьего — ответами без правок (владелец 29.09); редкая гонка с видимым дублем на проверенном пути — рассуждением и в «Чего не ловит» (28.09); молча пропавшая запись — чинить.
* **Тест — там, где дефект.** Сохранение или расчёт на сервере — IT на Testcontainers; только интерфейс — тест фронта на поведение; обе стороны — оба. Правка в N местах — N тестов, у каждого своя мутация.
* **Мутации** — на итоговом коде. Сначала та же команда на чистом коде — зелёная; «красно» — только с именем упавшего теста; бэк — через `bash` и `./mvnw`; многострочный образец — с переводами строк файла (CRLF).
* **Правка, которая начинает показывать отказ, мерит и успех** (ANO-208).
* **Замер** — через продукт, не SQL. Поиск — по значению, выдачу не обрезать; `grep -i` не складывает регистр кириллицы. «Недостижимо», «не зависит» и «решения не было» — только после грепа всех мест и всех планов.
* **Старые спеки `*-design.md` не править:** ворота спек требуют сверки в каждой изменённой; смену решения фиксирует спека правки.
* **Несколько PR с общими файлами** — вливать по одному, сочетание прогнать до вливания. Стопка — перед вливанием нижнего перенацелить верхний на `main`.
* **Метка «меняет-данные»** — на PR, где миграция намеренно меняет живые данные.
* **Объяснение, понадобившееся в чате,** — в справку «?» в интерфейсе, в той же задаче.
