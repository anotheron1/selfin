**Цель:** «Сегодня» на деталях дизайн-системы по доскам холста лица, первый вход из четырёх вопросов, подсказки первого дня с выключателем.

**Стек:** Java 21 / Spring Boot, React 18 / TypeScript, vitest, JUnit 5 + Testcontainers.

## Общие условия

* Сборка: `JAVA_HOME="/c/Users/Kirill/.jdks/jbr-21.0.8" ./mvnw verify` из `backend` — юниты и IT; фронт — `npm test -- --run`, `npx tsc --noEmit`, `npm run build` из `frontend`.

## PR 1. «Сегодня» на новых деталях

### Задача 1.0. Сверка «Осталось потратить» с журналом — до кода

Стенд, тестовый человек. Каждая строка блока «Осталось потратить» на Дашборде, включая «раньше по плану», ищется в «Журнале». Всё нашлось — строка в «Выполнено». Нет — вопрос владельцу таблицей «было / почему плохо / стало / почему лучше», код ждёт ответа.

### Задача 1.1. Состав дня в точке траектории (п. 8, ANO-98)

* Тест `PocketEngineTest`: день с доходом, бронью и ожиданием — у точки три строки с типами и суммами; сумма доходов строк равна `income` точки, расходов — `expense`; у сегодняшней точки — просрочка и сегодняшние строки; прогноз строкой не становится.
* Тест `PocketServiceTest`: имя категории вписано и в строки дня.
* IT: ответ `/pocket` несёт `trajectory[].items`.
* Правка: `PocketResultDto.TrajectoryPoint` — поле `items` (`List<UpcomingItem>`); обход в `PocketEngine` кладёт строки дня; `PocketService.withCategoryNames` берёт id и из точек. Фронт: тип `TrajectoryPoint.items`.

### Задача 1.2. Геометрия пейзажа и клеток (п. 2)

* `lib/cells.ts`: дни по неделям и месяцам, ступень цвета по остатку.
* Тесты `landscape.test.ts`, `cells.test.ts`: склон ниже нуля даёт воду, ниже НЗ — туман, хвост после срока — дымку; солнце стоит у дохода срока и называет его; мелкий доход раньше — малое солнце без подписи; клетка с минимумом — самая тёмная.

### Задача 1.4. Плитки и «Из чего число» (пп. 3, 4, 5)

* `lib/todayTiles.ts`: три плитки в обычном случае, две без прогноза, песочная «впритык» при стороже `FORECAST`. Тест по трём состояниям.

### Задача 1.5. Нехватка, НЗ и «Сдвинуть» (п. 6)

* `gapMode.ts` отдаёт строки «Можно сдвинуть» объектами — текст и ссылка на строку плана или хотелку, — а не готовыми строками. Тест `gapMode.test.ts` переписывается под объекты, тексты прежние.

### Задача 1.6. Впритык (п. 7)

### Задача 1.7. Лист дня и журнал на дату (п. 8)

### Задача 1.8. Перерыв и обычные траты (пп. 9, 10)
