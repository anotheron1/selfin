# Selfin

Форвардный личный финдиректор для российской реальности. Отвечает на вопрос **«сколько я могу потратить и дотяну ли до следующего дохода»** — не ведёт учёт прошлого.

Java/Spring (`backend/`) + React/TypeScript/Vite (`frontend/`).

```bash
JAVA_HOME="/c/Users/Kirill/.jdks/jbr-21.0.8" ./mvnw test     # юниты
JAVA_HOME="/c/Users/Kirill/.jdks/jbr-21.0.8" ./mvnw verify   # + 14 IT на Testcontainers
```

`npm test` — vitest, `npm run dev` — фронт.

Интеграционные тесты подключены через failsafe и по `mvnw test` **не запускаются**.

## Запреты

Нарушение любого — дефект продукта, а не вкусовщина. Основания: teardown часть Q.

1. **Категорийных бюджетов и лимитов по категориям не делаем. Никогда.** → Q №7
2. **Отчёт отклонений план-факт — не в состоянии по умолчанию.** Только по явному запросу. → кандидат №40
3. **Не продаём точность.** Обещание — «тебе не придётся считать», а не «посчитаем точнее». → screening 3.5
4. **Пейволл не показывать после ввода данных.** Цена раскрывается до того, как человек завёл счета. → кандидат №29

## Требования

5. **Состояние по умолчанию не требует правильности.** Ответ выдаётся на неполных и устаревших данных. Ни один экран не сообщает пользователю, что он завёл неправильно. → кандидат №33, P.7.3
6. **Ввод редкий, вывод частый.** Ре-якорь разделяет эти частоты; склеивать их обратно нельзя. → academic 11.1
7. **Уведомление — структурная часть продукта,** а не приём роста: момент наибольшей нужды совпадает с моментом наименьшей вероятности зайти самому. → academic 1.3, 8.1
8. **`breakdown[]` читается предложениями, а не арифметикой.** → ANO-22, O.7
9. **Быстрый ввод проектируется под кассу,** а не под вечерний разбор чеков; глубина ввода выбирается пользователем. → ANO-11, O.4

## Тексты на экране

10. **Не обвинять конкурентов — обещать состояние.** Рабочая формулировка: «знать, где будут мои деньги через неделю, без сюрпризов». → O.1
11. **Обещание продукта:** избежать провала, не потянувшись за кредиткой. → кандидат №46
12. **Никаких упрёков и оценок** — «вы превысили», «вы забыли», счётчиков несделанного. Предложение — да, упрёк — нет. → корпус, 283 упоминания тревоги
13. **Термины берём у пользователей:** «бегущий остаток» вместо «траектория», «забронировано» вместо «зарезервировано под план». → кандидаты №30, №45

## Данные респондентов

**Сырые материалы интервью в репозитории не хранятся. Нигде.** Не сохраняются переписки, аудио, скриншоты, имена, контакты, опознаваемые обстоятельства. Сохраняются выводы и обезличенные формулировки; респонденты обозначаются буквами.
→ `problem-interviews-guide.md` 7.1
