# Selfin

Форвардный личный финдиректор для российской реальности: «сколько я могу потратить и дотяну ли до следующего дохода». Java/Spring + React/TypeScript.

## Правила продукта

Код и интерфейс обязаны соответствовать **`docs/superpowers/specs/2026-09-01-product-rules.md`** — 13 правил на основаниях ANO-52 (запреты, требования, тексты на экране, работа с данными респондентов). **Прочитать перед любой работой над продуктовым поведением.**

Четыре запрета действуют всегда и чтения не требуют:

1. **Категорийных бюджетов и лимитов по категориям не делаем. Никогда.**
2. **Отчёт отклонений план-факт — не в состоянии по умолчанию.** Только по явному запросу.
3. **Не продаём точность.** Обещание — «тебе не придётся считать», а не «посчитаем точнее».
4. **Пейволл не показывать после ввода данных.**
